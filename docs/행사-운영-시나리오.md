# 행사 운영 시나리오

개발 지식이 없는 행사 담당자를 위한 인수인계 문서입니다. **처음이라면 바로 아래의 빠른 운영 순서만 먼저 읽으세요.** 세부 준비와 문제 해결은 뒤에서 확인할 수 있습니다.

## 빠른 운영 순서

### 사용할 주소

| 화면 | 주소 | 누가 사용하나요? |
|---|---|---|
| 참가자 | `https://outreach-balance-game-live.vercel.app/` | QR로 접속하는 참가자 |
| 관리자 | `https://outreach-balance-game-live.vercel.app/admin` | 질문을 조작하는 담당자 1명 |
| 실시간 결과 | `https://outreach-balance-game-live.vercel.app/results` | 프로젝터에 연결한 발표용 노트북 |
| 최종 결과 | `https://outreach-balance-game-live.vercel.app/final` | 마지막 결과 발표용 |

관리자 비밀번호는 이 문서나 단체 채팅에 적지 말고, 실제 조작 담당자에게 별도로 전달합니다.

### 이것만 따라 하면 됩니다

1. 관리자 노트북에서 `/admin`에 로그인합니다.
2. 행사명을 입력하고 `세션 시작`을 누릅니다.
3. 각 질문의 A·B 선택지, 선택 이모지(선택 사항), 제한시간을 입력하고 `질문 추가`를 누릅니다.
4. 질문 카드의 `▲ 위로`·`▼ 아래로`로 순서를 정리합니다.
5. 발표용 노트북에서 `/results`를 열고 F11로 전체 화면을 켭니다.
6. 휴대전화 2대 이상으로 참가자 주소에 접속해 질문 1~2개를 리허설합니다.
7. 실제 시작 직전에 관리자 화면의 `전체 투표 초기화`를 **한 번만** 눌러 리허설 투표를 지웁니다.
8. 참가자에게 QR을 보여 주고, 모두 접속하면 첫 질문의 `투표 시작`을 누릅니다.
9. 제한시간이 끝나면 `지금 종료`를 누르고 결과를 본 다음 다음 질문을 시작합니다.
10. 마지막 질문 종료 후 `/final`을 열고 화면 클릭·오른쪽 화살표·스페이스로 결과 슬라이드를 넘깁니다.

> `새 세션`을 누르면 질문이 복사되지 않습니다. 이미 질문을 모두 입력했다면 행사 직전에는 새 세션 대신 `전체 투표 초기화`를 사용하세요.

## 담당자 역할

최소 2명, 가능하면 3명으로 운영합니다.

| 역할 | 할 일 |
|---|---|
| 진행자 | 질문을 읽고 투표 시작·종료를 말로 안내 |
| 시스템 조작자 | `/admin`에서 질문 시작·종료 및 오류 확인 |
| 화면·현장 지원 | `/results` 송출, QR 안내, 접속 문제 대응 |

진행자와 시스템 조작자를 한 사람이 맡으면 무대 진행 중 잘못된 버튼을 누르기 쉬우므로 가능하면 분리합니다.

## 행사 담당자가 미리 정할 것

- 행사명과 진행 시간
- 진행자·시스템 조작자·화면 담당자
- 질문 목록과 순서
- 참가 예상 인원
- 행사장 Wi-Fi 사용 여부와 휴대전화 테더링 대안
- QR을 보여 줄 위치
- 결과를 매 질문마다 보여 줄지, 마지막에만 보여 줄지

권장 기본값은 **질문 8~12개, 질문당 30초, 전체 12~20분**입니다.

|---:|---|:---:|---|:---:|---:|
| 1 |  |  |  |  | 30초 |

| 3 |  |  |  |  | 30초 |
| 4 |  |  |  |  | 30초 |
| 5 |  |  |  |  | 30초 |
| 6 |  |  |  |  | 30초 |

| 8 |  |  |  |  | 30초 |

선택지는 휴대전화에서 한눈에 읽히도록 짧게 작성합니다. 정답이 있는 평가나 정치·건강·재정 등 참가자를 곤란하게 할 질문은 피합니다.

## 행사 전 리허설

1. 실제 행사 세션과 질문을 모두 입력합니다.
2. 오탈자가 있으면 행사 전에 해당 질문을 `삭제`하고 다시 등록합니다. 현재 화면에는 질문 문구 수정 기능이 없습니다.
3. 휴대전화 2대 이상에서 서로 다른 선택지에 투표합니다.
4. `/results`에서 남은 시간, 참여 인원, 종료 후 비율이 표시되는지 확인합니다.
5. `/final`에서 화면 클릭 또는 오른쪽 화살표로 모든 슬라이드가 넘어가는지 확인합니다.
6. 리허설이 끝나면 `전체 투표 초기화`를 누릅니다. 모든 질문이 다시 대기 상태가 되고 리허설 투표가 삭제됩니다.
7. 휴대전화에서 첫 질문을 다시 투표할 수 있는지 한 번 확인한 뒤, 행사 직전이면 다시 전체 초기화합니다.

`전체 투표 초기화`는 되돌릴 수 없습니다. 리허설 투표를 지우는 시점 외에는 진행자와 확인 후 사용합니다.

## 시작 30분 전 체크리스트

- [ ] 관리자 노트북에서 `/admin` 로그인
- [ ] 질문 문구·순서·제한시간 최종 확인
- [ ] 리허설 투표 전체 초기화
- [ ] 발표용 노트북에서 `/results` 열기 및 F11 전체 화면
- [ ] QR을 실제 휴대전화로 스캔
- [ ] Wi-Fi와 휴대전화 데이터에서 각각 접속 확인
- [ ] 발표용 노트북의 절전 모드와 화면 보호기 해제
- [ ] 진행자와 `투표 시작`·`지금 종료` 신호 합의

## 실제 진행 멘트와 조작

### 시작 안내 예시

> 화면의 QR을 휴대전화로 찍어 주세요. 닉네임은 입력해도 되고, 닉네임 없이 참여해도 됩니다. 질문이 나오면 A 또는 B 중 하나를 선택해 주세요.

접속 시간을 1~2분 줍니다. 별도의 현재 접속자 수 화면은 없으므로 진행자가 현장 반응을 보고 시작합니다.

### 질문 하나를 진행하는 순서

1. 진행자가 질문과 두 선택지를 읽습니다.
2. 시스템 조작자가 해당 질문의 `투표 시작`을 한 번 누릅니다.
3. 발표 화면에 질문과 카운트다운이 나타나는지 확인합니다.
4. 관리자 화면에서 총 투표 수가 늘어나는지 확인합니다.
5. 제한시간이 끝나면 `지금 종료`를 누릅니다.
6. 결과를 20~40초 정도 함께 본 뒤 다음 질문을 시작합니다.

화면은 네트워크 상태에 따라 몇 초 늦게 바뀔 수 있습니다. 같은 버튼을 여러 번 누르지 말고 3~6초 기다립니다. 새 질문을 시작하면 같은 세션에서 진행 중이던 이전 질문은 자동으로 종료됩니다.

### 마지막 결과

1. 마지막 질문을 `지금 종료`합니다.
2. 발표용 브라우저에서 `/final`을 엽니다.
3. 첫 화면을 클릭하거나 오른쪽 화살표·스페이스를 눌러 질문별 결과를 넘깁니다.
4. 왼쪽 화살표로 이전 슬라이드로 돌아갈 수 있습니다.
5. 발표가 끝나면 관리자 화면에서 로그아웃합니다.

## 관리자 버튼 주의사항

| 버튼 | 기능 | 주의사항 |
|---|---|---|
| `새 세션` | 현재 세션을 바꾸고 빈 세션 생성 | 기존 질문이 새 세션으로 복사되지 않음 |
| `투표 시작` | 질문 공개와 카운트다운 시작 | 진행자 신호 전에 누르지 않기 |
| `지금 종료` | 질문 투표 종료 | 종료 후에는 투표할 수 없음 |
| `초기화` | 해당 질문의 투표 삭제 및 대기 상태 복귀 | 되돌릴 수 없음 |
| `전체 투표 초기화` | 모든 질문의 투표 삭제 및 대기 상태 복귀 | 리허설 종료 시 사용, 되돌릴 수 없음 |
| `삭제` | 질문과 관련 투표 삭제 | 행사 진행 중 사용하지 않기 |
| `▲ 위로`·`▼ 아래로` | 질문 순서 변경 | 행사 시작 전에만 사용 권장 |

## 문제가 생겼을 때

| 증상 | 바로 할 일 |
|---|---|
| 일부 참가자만 접속 실패 | Wi-Fi를 끄고 개인 데이터 사용, QR 아래의 주소 직접 입력, 브라우저 새로고침 |
| 참가자에게 질문이 안 보임 | 관리자의 질문 상태가 `진행중`인지 확인하고 6초 기다린 뒤 새로고침 |
| 결과 숫자가 늦게 바뀜 | 3~6초 기다리고 발표 화면을 한 번 새로고침 |
| 잘못된 질문을 시작함 | `지금 종료` → 필요하면 해당 질문 `초기화` → 올바른 질문 시작 |
| 발표 화면만 문제 | 관리자 화면의 집계를 보고 진행자가 결과를 말로 안내 |
| 전체 서비스 접속 실패 | Wi-Fi 대신 테더링 시도, 2~3분 내 복구되지 않으면 손들기 방식으로 전환 |

행사를 오래 멈추면서 복구하지 않습니다. 이 게임은 보조 프로그램이므로 2~3분 안에 해결되지 않으면 구두 질문과 손들기로 계속 진행합니다.

## 알아둘 제한사항

- 같은 브라우저에서는 질문별 중복 투표를 막습니다.
- 다른 기기·다른 브라우저·시크릿 모드를 사용하면 다시 투표할 수 있습니다.
- 출석 확인, 본인 인증, 경품 추첨용으로 사용하면 안 됩니다.
- 참가자 화면과 결과 화면은 자동 갱신되지만 네트워크에 따라 몇 초 지연될 수 있습니다.

## 행사 후

1. 관리자 화면에서 로그아웃합니다.
2. 결과 보존이 필요하면 `/final`을 캡처합니다.
3. 데이터 삭제나 초기화는 행사 담당자 승인 없이 실행하지 않습니다.
4. 관리자 비밀번호를 여러 사람에게 공유했다면 행사 후 새 값으로 바꾸고 재배포를 요청합니다.

## 인수인계 완료 확인

- [ ] 담당자가 네 가지 주소를 받음
- [ ] 조작 담당자가 관리자 비밀번호를 별도 전달받음
- [ ] 질문과 순서를 확정함
- [ ] 운영자 2명 이상을 지정함
- [ ] 휴대전화 2대 이상으로 리허설함
- [ ] 리허설 투표를 초기화함
- [ ] 네트워크 장애 시 손들기로 전환한다는 원칙을 공유함

위 체크가 모두 끝나면 행사 담당자는 개발자 도움 없이 운영할 수 있습니다.
