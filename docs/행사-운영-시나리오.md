# 8월 16일 밸런스 게임 운영 안내

이 문서는 웹사이트를 처음 보는 행사 담당자를 위한 안내입니다. **행사 중에는 아래 ‘당일 운영표’만 보고 진행해도 됩니다.**

## 먼저 기억할 세 가지

1. 관리자 화면을 조작하는 사람은 **한 명만** 정합니다.
2. 질문마다 `투표 시작` → 기다리기 → `지금 종료` 순서입니다.
3. `새 세션`, `전체 투표 초기화`, `삭제`는 행사 중 누르지 않습니다.

관리자 비밀번호는 이 문서에 적지 않고 조작 담당자에게 따로 전달합니다.

## 행사 정보와 링크

- 행사일: **2026년 8월 16일(일)**
- 예상 참가자: 약 120명

| 누가 사용하나요? | 열어 둘 화면 |
|---|---|
| 참가자 휴대전화 | [참가자 투표 화면](https://outreach-balance-game-live.vercel.app/) |
| 조작 담당자 | [관리자 화면](https://outreach-balance-game-live.vercel.app/admin) |
| 프로젝터용 컴퓨터 | [실시간 결과 화면](https://outreach-balance-game-live.vercel.app/results) |
| 마지막 결과 발표 | [엔딩 화면](https://outreach-balance-game-live.vercel.app/final) |

관리자 화면은 휴대전화에서도 사용할 수 있습니다. 다만 결과 화면은 프로젝터와 연결된 컴퓨터에 띄우고, 관리자 조작은 한 기기에서만 하는 것이 안전합니다.

## 당일 운영표

### 시작 30분 전

- [ ] 관리자 화면에 로그인했습니다.
- [ ] 질문 내용과 순서를 확인했습니다.
- [ ] 휴대전화 2대로 실제 투표를 시험했습니다.
- [ ] 시험이 끝난 뒤 `전체 투표 초기화`를 한 번 눌렀습니다.
- [ ] 프로젝터용 컴퓨터에서 결과 화면을 열고 F11로 전체 화면을 켰습니다.
- [ ] 참가자 QR이 실제 휴대전화에서 열리는지 확인했습니다.

> 질문을 이미 입력했다면 `새 세션`을 누르지 마세요. 새 세션에는 기존 질문이 복사되지 않습니다.

### 참가자를 접속시킬 때

진행자가 다음처럼 안내합니다.

> 화면의 QR을 휴대전화로 찍어 주세요. 닉네임은 쓰지 않아도 됩니다. ‘시작하기’를 누른 뒤 질문이 나올 때까지 기다려 주세요.

1~2분 정도 기다린 뒤 첫 질문을 시작합니다. 현재 접속자 수를 따로 보여 주는 기능은 없습니다.

### 질문 하나를 진행할 때

아래 여섯 단계를 질문마다 반복합니다.

1. 진행자가 질문과 A·B 선택지를 읽습니다.
2. 조작 담당자가 해당 질문의 `투표 시작`을 **한 번만** 누릅니다.
3. 프로젝터에 질문과 남은 시간이 보이는지 확인합니다.
4. 관리자 화면의 `총 ○명` 숫자가 늘어나는지 확인합니다.
5. 시간이 끝나면 `지금 종료`를 누릅니다.
6. 결과를 함께 본 뒤 다음 질문으로 넘어갑니다.

화면 반응이 늦으면 버튼을 다시 누르지 말고 6초 기다립니다.

### 마지막 질문이 끝났을 때

1. 마지막 질문의 `지금 종료`를 누릅니다.
2. 프로젝터용 컴퓨터에서 [엔딩 화면](https://outreach-balance-game-live.vercel.app/final)을 엽니다.
3. 화면 클릭, 오른쪽 화살표 또는 스페이스로 다음 결과를 보여 줍니다.
4. 왼쪽 화살표를 누르면 이전 결과로 돌아갑니다.

## 버튼 뜻

| 버튼 | 언제 누르나요? | 주의 |
|---|---|---|
| `투표 시작` | 진행자가 질문을 읽은 직후 | 한 번만 누르기 |
| `지금 종료` | 제한시간이 끝났을 때 | 종료 후에는 추가 투표 불가 |
| `초기화` | 질문 하나만 다시 시험할 때 | 해당 질문 투표가 삭제됨 |
| `전체 투표 초기화` | 리허설이 모두 끝난 직후 | 모든 투표가 삭제되므로 행사 중 금지 |
| `새 세션` | 완전히 다른 행사를 새로 만들 때 | 기존 질문이 복사되지 않음 |
| `삭제` | 잘못 입력한 질문을 행사 전에 지울 때 | 관련 투표도 함께 삭제됨 |
| `▲ 위로`·`▼ 아래로` | 행사 전에 질문 순서를 바꿀 때 | 진행 중에는 변경하지 않기 |

## 문제가 생겼을 때

### 참가자에게 질문이 안 보입니다

1. 관리자 화면에서 해당 질문이 `진행중`인지 확인합니다.
2. 6초 기다립니다.
3. 그래도 안 보이는 참가자만 화면을 새로고침합니다.

### 잘못된 질문을 시작했습니다

1. 잘못 연 질문의 `지금 종료`를 누릅니다.
2. 올바른 질문의 `투표 시작`을 누릅니다.
3. 잘못 연 질문을 나중에 다시 사용하려면 그 질문의 `초기화`를 누릅니다.

### 결과 숫자가 늦게 바뀝니다

3~6초 기다린 뒤 결과 화면만 한 번 새로고침합니다. 참가자에게 다시 투표하라고 안내하지 않습니다.

### 관리자 컴퓨터에 문제가 생겼습니다

휴대전화에서 관리자 링크를 열고 로그인해 계속 진행할 수 있습니다. 두 기기에서 동시에 버튼을 누르지 않습니다.

### 2~3분 안에 복구되지 않습니다

이 게임 때문에 행사를 오래 멈추지 않습니다. 진행자가 A·B를 읽고 참가자가 손을 드는 방식으로 계속합니다.

## 리허설 방법

1. 실제 행사에 사용할 질문을 모두 입력합니다.
2. 휴대전화 2대에서 A와 B를 각각 투표합니다.
3. 결과 화면과 엔딩 화면을 확인합니다.
4. 관리자 화면을 휴대전화에서도 열어 버튼이 잘 눌리는지 확인합니다.
5. 리허설이 모두 끝나면 `전체 투표 초기화`를 누릅니다.
6. 질문이 모두 `대기` 상태이고 투표 수가 0명인지 확인합니다.

오탈자는 행사 전에 해당 질문을 `삭제`한 뒤 다시 등록합니다. 현재 질문 문구를 직접 수정하는 기능은 없습니다.

## 알아둘 점

- 같은 브라우저에서는 한 질문에 한 번만 투표할 수 있습니다.
- 다른 기기·다른 브라우저·시크릿 모드를 사용하면 다시 투표할 수 있습니다.
- 출석 확인, 본인 인증, 경품 추첨용으로 사용하지 않습니다.
- 참가자 화면과 결과 화면은 자동으로 바뀌지만 통신 상태에 따라 몇 초 늦을 수 있습니다.

## 행사 종료 후

1. 필요한 결과는 엔딩 화면을 캡처해 보관합니다.
2. 관리자 화면에서 로그아웃합니다.
3. 데이터 삭제나 초기화는 담당자 승인 없이 실행하지 않습니다.

이 문서와 관리자 화면의 `운영 도움말`만 전달받으면 개발자 없이 행사를 진행할 수 있습니다.
